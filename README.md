# VAULT 🎰

VAULT is a modular Discord economy and casino bot built for Discord servers.

It combines a persistent server economy with casino games, jackpots, leaderboards, and configurable economy systems.

---

## ✨ Features

### Economy

- 💰 User balances
- 💸 Give / transfer Ethers
- 🎁 Role-based gifts
- 🧾 Monthly economy tax
- 🏦 Internal House Purse

### Casino

- 🎰 Slots
- 🪙 Coinflip
- 🃏 Blackjack
- 💣 Mines
- 📈 Crash
- 🎡 European Roulette
- 🎲 Double or Nothing
- 👥 Multiplayer games
- 🎰 Multiple slot machines
- 💎 Jackpot

### Social

- 🏆 Leaderboard
- 📊 Personal rank card

### Utility

- 🚀 Account onboarding
- 📖 Help command
- 🧩 Permanent information embeds
- ⚙️ Economy configuration
- 🔐 Developer-only House controls
